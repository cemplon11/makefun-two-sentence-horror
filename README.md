A two-sentence horror story in exactly 205 characters: a wife who
sleepwalks to the kitchen every night, a chair pulled out each morning,
and a count that comes out one higher than the chairs the house owns.
The program is pure-stdlib Python and writes those two sentences,
deterministically, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

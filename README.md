A horror story told in exactly two sentences and 205 characters.
Every night since the move, the narrator's wife sleepwalks to the
kitchen; every morning one more chair stands pulled out from the
table. The second sentence turns the routine into something worse:
six chairs pulled out in a house that owns only five, which means
someone else has been sitting at their table all along. The program
is pure-stdlib Python and writes those two sentences, deterministically,
to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
